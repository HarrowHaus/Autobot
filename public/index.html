What this alpha actually does

1

Upload one file

A Stripe Payout Reconciliation Itemized CSV export. That is the only supported input right now.

2

We validate it strictly

Unrecognized columns, mixed currencies, or unknown transaction categories are reported as errors, not guessed at.

3

You get a reconciliation report

Per-payout totals and any variance between the file's stated net and an independently recalculated net. This is informational, not an accounting import.

Try it

This is an early alpha, not production software. Your file is processed in memory for this one request and is not written to a database — but treat every result here as informational, not accounting-ready, until it's been reviewed. Read the privacy policy.

Access

This is a free, early alpha. There is no payment or subscription — purchasing isn't enabled. Usage is rate-limited to keep it available for everyone testing it.
