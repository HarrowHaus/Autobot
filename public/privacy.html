Privacy Policy

Last updated: 2026

The short version

We never store the contents of the file you upload. It's processed in memory for the duration of a single request and discarded immediately after we send you the reconciliation report back. We don't need a database of your transactions to run this service, so we don't keep one.

What we do store

  • Email address: only if you provide one, which happens after your first free run. It's used to track free-trial usage and (since billing is disabled) an always-zero credit balance placeholder for that purpose.
  • Usage metadata: that a conversion attempt happened, which processor was used, whether it succeeded, and row/payout counts — never the transaction data itself.
  • Rate-limit and free-trial state: your IP address, kept in short-lived form only long enough to enforce rate limits and the one-free-run policy.
  • "Missing platform" feedback: if you use the "don't see your processor" box, we store the text you typed.

Billing is disabled in this alpha (no checkout, no payment processor is contacted), so no payment data of any kind is collected. The database has tables reserved for future credit-pack purchases and API keys, but they stay empty while billing is off.

What we don't do

  • We don't connect to your bank, Stripe, QuickBooks, or Xero accounts. You download an export yourself and upload it here; nothing is written back anywhere automatically. No OAuth, no standing access to your financial accounts.
  • We don't store column headers or any other content from files that fail validation.
  • We don't sell or share your data with third parties beyond the infrastructure provider necessary to run the service (Cloudflare for hosting).
  • We don't use your uploaded data to train any model. There's no model in this product — the validation and reconciliation logic is deterministic code, not AI.

Infrastructure

The service runs on Cloudflare Workers. Rate-limiting and free-trial state are stored in Cloudflare KV. Cloudflare D1 is provisioned for future use but does not currently store any per-user data.
