Privacy Policy

Last updated: 2026

The short version

We never store the contents of the file you upload. It's processed in memory for the duration of a single request and discarded immediately after we send you the reconciliation report back. We don't need a database of your transactions to run this service, so we don't keep one.

We don't ask who you are

There are no accounts. We don't ask for your email, there's no sign-up, no login, no API key, and no payment of any kind — that entire system has been removed from the codebase, not merely switched off. Nothing you upload is linked to an identity, because we don't have one for you.

Exactly what gets written down

Two things go into our database (Cloudflare D1):

  • An anonymous usage row per conversion attempt: a random ID, which processor was selected, whether it succeeded or failed, an error code if it failed, and how many rows were included. No IP address, no identity, and no transaction data. We use this to know whether the alpha works at all.
  • "Missing platform" feedback: if you type into the "don't see your processor" box, we store that text (truncated to 500 characters) and nothing else.

One thing goes into short-term storage (Cloudflare KV):

  • Rate-limit counters keyed by your IP address. These are set to expire automatically about a minute after they're written, and are used solely to stop one person from overwhelming the service.

Retention: KV rate-limit counters self-delete within roughly a minute. The two D1 tables above are currently kept indefinitely; because neither contains identifying information or file content, there is nothing in them to tie back to you. If that changes, this page changes first.

What we don't do

  • We don't store the contents of your file, any column from it, or any derivative of it — including from files that fail validation.
  • We don't connect to your bank, Stripe, QuickBooks, or Xero accounts. You download an export yourself and upload it here; nothing is written back anywhere automatically. No OAuth, no standing access to your financial accounts.
  • We don't sell or share your data with third parties beyond the infrastructure provider necessary to run the service (Cloudflare for hosting).
  • We don't use your uploaded data to train any model. There's no model in this product — the validation and reconciliation logic is deterministic code, not AI.

Infrastructure

The service runs on Cloudflare Workers, with Cloudflare D1 for the two metadata tables described above and Cloudflare KV for expiring rate-limit counters. Cloudflare also processes request logs on our behalf as part of hosting.

Verify this yourself

You don't have to take our word for any of the above. The source is published — src/lib/signals.ts contains every database write this service makes, and it is about twenty lines long.
