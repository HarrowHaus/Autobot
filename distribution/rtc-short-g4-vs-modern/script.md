# Script — ~45–55 seconds

**Hook:** RustChain does something most compute networks would never do: an old PowerPC G4 gets a higher reward weight than a modern x86 machine.

In the current RIP-200 multiplier table, a G4 is listed at **2.5×**. Modern Intel and AMD entries are **0.8×**.

That does **not** mean the G4 is faster. It means RustChain deliberately rewards hardware antiquity and preservation instead of raw compute throughput.

The network still checks that a miner is a real physical machine before using its hardware classification. So the story is not “old computers magically outperform new ones.” The story is that RustChain assigns more economic weight to preserved vintage silicon.

To verify it yourself, open the multiplier table in the RustChain repo, then compare it with the live miner list at rustchain.org.

**End card:** Proof of Antiquity: hardware age is part of the protocol, not a benchmark claim.
